## Key takeaways (condensed)

- **Two parallel "recent context" mechanisms exist and behave oppositely on isolation**: the durable `session_store` layer is correctly project-scoped on disk; the in-process `SessionBuffer` is not scoped at all and leaks across projects within a shared process (CHZ-AUD-B-04, Critical — the headline finding).
- **Content genuinely persists between sessions** (not just metadata) in the durable layer, in plaintext, with no time-based expiry, and with a redaction pass that only catches `key=value`-syntax secrets, not prose-phrased ones (CHZ-AUD-B-02, CHZ-AUD-B-03).
- **Fail-open behavior is real and confirmed by execution**, not just claimed: both a corrupted context file and a read-only context directory leave routing/response-delivery fully intact.
- **A structurally separate "success" path (emergency BUDGET fallback) silently skips all context/ledger recording** for turns that still succeed from the caller's point of view (CHZ-AUD-B-05).
