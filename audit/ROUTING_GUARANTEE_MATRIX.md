## Reading the matrix

The single sentence that resolves the audit's central adversarial question:

> **In Chuzom's default configuration, "routing" at the Claude Code push-hook layer means "a
> real external model may be called and its answer offered as an unverified suggestion" — it
> does not mean "Claude's answer is guaranteed to come from that model."** Genuine,
> non-bypassable turn replacement only happens under the non-default `zero_claude=True`
> setting, and even then only when Direct Execution is administratively enabled and the
> external call succeeds.

Separately, at the litellm/API dispatch layer itself (i.e., once Chuzom has decided to call a
model), execution is real and canary-provable end-to-end with 0% lost-response and 0% true
wrong-provider rate across the 48-prompt sample — the guarantee gap is entirely about whether
that execution is allowed to be authoritative for the current Claude Code turn, not about
whether the call itself happens or is truthfully recorded.
